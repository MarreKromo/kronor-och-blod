# SVERIGE: Kronor & Blod
Historiskt kartbaserat RPG. Startår 1250, första spelregion Västergötland.

## Projektstatus
- **KB-00:** GDD v1.0 finns i `docs/`.
- **KB-01:** Projektstruktur (pågår tills GitHub-uppladdning och kontroll är godkända).
- **KB-02:** Historiskt underlag och spelkarta (ej påbörjad).

## Arbetsregler
1. Ett avgränsat paket i taget.
2. Dokumentera beslut innan större kodändringar.
3. Testa på iPhone/Safari och notera PASS/FAIL.
4. Gör commit efter godkänt steg.
5. Uppdatera `docs/DAILY_LOG.md` innan arbetspasset avslutas.

## Vision
Historiskt trovärdig värld som spelaren kan förändra. Prototyp A är kartbaserad; arkitekturen ska kunna utökas med hybridmiljöer (C) utan att världssimuleringen skrivs om.
